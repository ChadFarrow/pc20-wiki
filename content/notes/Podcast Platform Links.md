# Podcast Platform Links

Podcast Platform Links is a reference documenting how to construct a URL to a given show or episode on each podcast platform.

## Why it matters

Podcasting is distributed by design, which is a virtue for publishing and a problem for linking: the same episode exists at a different address in every app, and there is no registry mapping between them. Anyone building a share button, a directory or a chapter link runs into this immediately.

## How it works

The document catalogues which foreign keys each platform routes on — feed URL, platform-specific show ID, [[RSS]] GUID — so a URL can be built with confidence rather than looked up. Where a platform offers an API for resolving links instead, that is documented too, and where it offers nothing, that is recorded as well.

## Open questions

- Platform URL schemes change without notice; the reference is only as good as its last update
