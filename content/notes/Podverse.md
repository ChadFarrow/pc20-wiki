# Podverse

Podverse is an open source podcast app that implements the Podcasting 2.0 feature set rather than treating it as optional.

## Why it matters

A namespace tag is theoretical until an app renders it. Podverse is one of the clients that makes [[Chapters]], [[Transcripts]] and [[Soundbites]] visible to listeners, which is what moves a tag from written-down to real. It is also self-hostable, so the app is not a single company's decision.

## How it works

The project is a TypeScript monorepo covering the API, the web app and the mobile clients, shipping on iOS, Android, F-Droid and web. [[Value 4 Value]] payments are built in, so listeners can pay creators from the same place they listen. The whole stack can be run locally — see [[Self-hosting]].
